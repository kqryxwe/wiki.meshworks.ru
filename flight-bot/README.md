# Flight Bot — подбор самых дешёвых маршрутов через Aviasales

Софт, который по заданному запросу («откуда, куда, с какими остановками и на
сколько ночей») автоматически перебирает даты вылета, длительность остановок и
альтернативные аэропорты и находит **самые дешёвые комбинации авиабилетов**.

Поиск идёт **не парсингом сайта**, а через официальный бесплатный API данных
Aviasales (Travelpayouts) — он отдаёт кэш реальных цен, найденных
пользователями Авиасейлс. К каждому найденному перелёту бот даёт прямую ссылку
на страницу покупки на aviasales.ru.

## Пример задачи

> Вылетаю из Актау, хочу 2–4 ночи побыть в Стамбуле, потом 7–10 ночей отдохнуть
> в Черногории (Тиват или Подгорица — где дешевле), и вернуться в Актау.
> Вылет где-то 1–15 августа. Где самые лучшие цены?

```bash
python -m flight_bot \
    --origin SCO \
    --stop IST:2-4 \
    --stop TIV,TGD:7-10 \
    --dates 2026-08-01..2026-08-15 \
    --top 5
```

Бот переберёт все комбинации (15 дат вылета × 3 варианта по Стамбулу ×
4 варианта по Черногории × 2 аэропорта = 360 маршрутов), оценит каждый по
кэшу цен и выведет топ-5 самых дешёвых, например:

```
#1  TOTAL 48 300 ₽  (2026-08-04 → 2026-08-14)
  2026-08-04  SCO → IST  14 200 ₽  TK371  direct
    https://www.aviasales.ru/search/...
  2026-08-07  IST → TGD  11 900 ₽  TK1087  direct
    https://www.aviasales.ru/search/...
  2026-08-14  TGD → SCO  22 200 ₽  TK  1 transfer(s)
    https://www.aviasales.ru/search/...
```

## Установка

Нужен Python 3.9+.

```bash
cd flight-bot
pip install -r requirements.txt
```

### Токен API (бесплатно)

1. Зарегистрируйтесь на <https://www.travelpayouts.com/> (это официальная
   партнёрская платформа Aviasales).
2. В кабинете создайте проект и скопируйте **API token**.
3. Экспортируйте его:

```bash
export TRAVELPAYOUTS_TOKEN="ваш_токен"
```

(или передавайте через флаг `--token`).

## Как задавать запрос

| Параметр | Формат | Пример |
|---|---|---|
| `--origin` | IATA-код города/аэропорта вылета | `SCO` (Актау) |
| `--stop` | `КОДЫ:НОЧИ`, можно несколько подряд — это порядок маршрута | `IST:2-4`, `TIV,TGD:7-10` |
| `--dates` | окно дат вылета `ОТ..ДО` или одна дата | `2026-08-01..2026-08-15` |
| `--no-return` | не возвращаться в город вылета | |
| `--direct` | только прямые рейсы | |
| `--currency` | валюта: `rub`, `usd`, `eur`, `kzt` | `--currency kzt` |
| `--top` | сколько вариантов показать | `--top 10` |

Несколько кодов через запятую в `--stop` — это альтернативы («Тиват **или**
Подгорица»): бот сам выберет, куда лететь дешевле.

Полезные коды: Актау `SCO`, Стамбул `IST` (город, включает оба аэропорта),
Тиват `TIV`, Подгорица `TGD`, Белград `BEG` (частая дешёвая альтернатива для
Черногории — дальше автобусом).

## Telegram-бот

Тот же поиск можно поднять как Telegram-бота:

```bash
export TRAVELPAYOUTS_TOKEN="..."
export TELEGRAM_BOT_TOKEN="токен от @BotFather"
python -m flight_bot.telegram_bot
```

Запрос в чате:

```
/search SCO IST:2-4 TIV,TGD:7-10 2026-08-01..2026-08-15
```

## Как это работает

1. Для каждой пары «откуда → куда» бот одним запросом забирает из API кэш
   минимальных цен на каждый день месяца (`grouped_prices`), с кэшированием —
   сетевых запросов мало даже при широком окне дат.
2. Планировщик перебирает все допустимые комбинации: дата вылета × длительность
   каждой остановки × альтернативные аэропорты.
3. Каждая комбинация оценивается суммой цен по сегментам; топ-N самых дешёвых
   выводится со ссылками на покупку.

## Ограничения

- Цены берутся из кэша Aviasales: это реальные найденные цены, но они могли
  измениться — всегда проверяйте по ссылке перед покупкой. Ссылка открывает
  живой поиск на нужные даты.
- Если по какому-то сегменту в кэше нет цены, комбинация пропускается; бот
  подскажет, каких сегментов не хватило — попробуйте расширить окно дат или
  добавить альтернативные аэропорты.
